# Guia rápido de uso

Este guia orienta o operador no uso diário da Régua Editorial.

## Para que serve

A ferramenta apoia o tratamento de matérias do Caderno Municípios no EGBANET. Ela permite:

- obter o arquivo original da matéria;
- preparar o documento conforme as regras editoriais aprovadas;
- conferir a prévia;
- medir tarja e conteúdo;
- calcular o valor da publicação;
- salvar o cálculo;
- consultar registros anteriores;
- emitir relatórios e exportar dados.

## Antes de usar

- entre no EGBANET com seu usuário habitual;
- use o perfil do Chrome definido para a operação;
- não limpe os dados do navegador;
- confirme que a matéria está em uma página compatível;
- mantenha o Microsoft Word disponível quando for trabalhar com DOC ou RTF.

## Caso de uso 1 — Processar uma matéria DOCX

1. Abra a matéria no EGBANET.
2. Abra a Régua Editorial.
3. Confira protocolo, cliente e identificação da matéria.
4. Selecione **Processar matéria**.
5. Aguarde a preparação do documento.
6. Revise a prévia apresentada.
7. Confira a medição e o valor.
8. Salve o cálculo.

Use este fluxo quando o arquivo original já estiver em formato DOCX.

## Caso de uso 2 — Processar DOC ou RTF

Quando o Microsoft Word estiver instalado:

1. abra a matéria no EGBANET;
2. inicie o processamento;
3. aguarde a conversão automática para DOCX;
4. revise a prévia;
5. confira medição e valor;
6. salve o cálculo.

Quando a conversão automática não estiver disponível:

1. baixe o arquivo original;
2. converta-o para DOCX no Word;
3. volte à Régua Editorial;
4. adicione o DOCX convertido;
5. continue o processamento normalmente.

> [!IMPORTANT]
> Nunca substitua ou sobrescreva o arquivo original recebido do EGBANET.

## Caso de uso 3 — Consultar um cálculo salvo

1. Abra a área de consultas.
2. Informe a data, o protocolo ou o cliente.
3. Selecione o registro desejado.
4. Confira medidas, valores e data do cálculo.
5. Quando necessário, use o identificador da matéria para retornar à página correspondente no EGBANET.

## Caso de uso 4 — Emitir relatório

1. Abra a área de relatórios.
2. Escolha uma data ou intervalo.
3. Confira a quantidade de registros e os totais.
4. Exporte em:
   - **CSV**, para planilhas;
   - **JSON**, para integração, conferência técnica ou uso em ferramentas de IA.

Antes de compartilhar o relatório, confirme se o destinatário está autorizado a receber os dados.

## Caso de uso 5 — Corrigir uma pendência

Quando a ferramenta bloquear o processamento:

1. leia a mensagem apresentada;
2. identifique a pendência no documento;
3. corrija uma cópia do arquivo no Microsoft Word;
4. salve em DOCX;
5. processe novamente;
6. confirme que a pendência foi resolvida.

Bloqueios podem ocorrer, por exemplo, quando há tabelas ou objetos não permitidos pelas regras editoriais.

## Conferências antes de salvar

Verifique sempre:

- se a matéria correta está aberta;
- se protocolo e cliente correspondem ao documento;
- se a prévia não apresenta cortes ou conteúdo ausente;
- se tarja e conteúdo foram identificados corretamente;
- se a medida e o preço são coerentes;
- se não há alerta ou bloqueio pendente.

## Cuidados com os registros

Os cálculos são guardados localmente no perfil do Chrome.

Para evitar perda de dados:

- não troque de perfil do navegador durante a operação;
- não use limpeza automática de dados do Chrome;
- não remova a extensão sem orientação;
- exporte relatórios periodicamente conforme a rotina definida pela gestão.

## Quando acionar o suporte

Registre uma ocorrência quando:

- a extensão não abrir na página da matéria;
- os dados da matéria não forem reconhecidos;
- a conversão falhar repetidamente;
- a prévia estiver incompleta;
- a medição ou o valor parecer incorreto;
- um cálculo salvo desaparecer;
- o relatório não corresponder aos registros.

Informe:

- data e horário;
- ação realizada;
- formato do arquivo;
- mensagem exibida;
- versão da extensão;
- se o erro ocorreu novamente após fechar e reabrir o Chrome.

Não envie documentos de produção, senhas, cookies ou dados sensíveis por canais não autorizados.
